# Scenes and assets

**Shot design.** Sketch the opening, turning point and final hold. For each, pick a subject, a foreground edge, a horizon or vanishing point and the relation of the call to action to the subject. A pan reveals spatial context. A dolly changes perspective. A crop or zoom changes framing. Use one of these for a specific narrative reason. A 2.5D scene can use a small number of depth planes and a restrained parallax range. Test the edges at both input extremes, when overscan is smallest. Keep type in a stable plane.

**Reactive scene.** Map normalized pointer or keyboard input to a target, smooth it with elapsed-time-aware interpolation and clamp travel before important content is obscured. Separate camera pose, object pose and interaction state. For an orbitable object expose left/right and reset controls, an accessible name and a static view. For real-time 3D establish framing using object bounds and aspect ratio. Use a readable silhouette and a key, fill or environment that reveals material roughness. Test the fallback when WebGL is unavailable or its context is lost.

**Procedural work.** Own one deterministic seed per variant. Separate world coordinates from screen coordinates and account for device pixel ratio when mapping pointer input. In a shader, normalize distance fields to aspect ratio; use smooth thresholds for antialiasing and bound time-driven displacement. Draw repeated geometry in batches or instances. Reuse particle buffers and cap count and resolution from measured frame cost. Dispose of textures, buffers and listeners when leaving the scene. Keep a poster or SVG fallback for low-power and reduced-motion modes.

**Asset production.** Define silhouette, crop, depth ordering and light direction first. Keep an editable layered master. For a generated image record the producing tool, permitted use, prompt or brief, date and selected output. For a model retain the original mesh, material and texture sources, coordinate convention and export settings. Check normals, UV seams, texture color space and scale in the target renderer. For rigged animation inspect the rest pose, weight deformation, root motion, clip timing and loop seam in the exported asset. Run the actual DCC, renderer or encoder before claiming those capabilities on a host.

**Delivery.** Keep attribution and license records associated with each input, including third-party textures, typefaces and audio. Render an original asset, use an owner-supplied reference, or obtain licensed media appropriate to the brief. Export image variants for the target resolution. For a video plate check frame rate, alpha interpretation, color space and the join after compression. Record dimensions, byte size, and checksum for the approved derivative. A small static composition is a valid result when it best serves the work.

**Audit the source of motion cues.** View the plate alone at its final crop. Mark crests, highlights, reflections and shadows that imply a particular instant. Keep stationary shore, depth and albedo separate from time-dependent lighting. Inspect the final composite with each suspect layer muted, then freeze the simulation. Recognizable waves that survive both inspections belong to the source artwork or a second composited layer. Warping that image shifts a fixed pattern; alpha blending it over an undistorted copy can anchor or double the pattern. A clean masked water region, separate reflected scenery and a single surface-normal field can resolve the conflict. If the source cannot be separated, record the limit before commissioning a more detailed solver.

**Choose the smallest surface model that conveys the interaction.** Use authored 2D layers for a fixed illustrative view. For slow apparent flow, advect a tileable signal by a velocity field (for uniform flow sample at `p − u t`). For isolated impacts on unobstructed water an analytic ring in world units may suffice. For propagation around obstacles, use a local height field. One shallow-water approximation is `h_tt + γ h_t = div(c² grad h)`, with wave speed `c ≈ √(g d)` at water depth d. Limit the fixed timestep for the chosen grid and stencil. A dry face with zero normal flux reflects a wave; drag dissipates its energy. Masking the final ring can hide the crest while letting it reappear beyond the obstacle. Compare a wet-margin strike, an obstructed path and a dry strike.

Derive the shading normal from the height gradient, e.g. normalize `(−∂h/∂x, 1, −∂h/∂z)` for Y-up. Use that normal for reflected features and highlights, with view-angle weighting. Project world-space impacts through the camera and filter detail smaller than a screen pixel. Strike near and far water with the same impulse; look for foreshortening, changing apparent radius and a visible consequence where the front reaches the shore. Report which cues survive the final contrast, depth of field and viewport crop.

# Motion and input

Write the start pose, end pose, trigger, exit and reduced-motion equivalent. On an interrupted transition, sample the visible pose and reverse or retarget from there. For easing curves, read the computed transform or animated value at interruption. Elapsed time divided by duration gives clock progress and can differ substantially from visible progress. Keep interaction state separate from presentation progress. For a disclosure, the state can be closed, opening, open or closing. A second press during opening begins closing from the current pose. After cancellation, only the latest transition may commit focus or hide a node. Before hiding a panel that holds focus, explicitly return focus to its trigger. Test a reversal at an observed intermediate pose and check the new endpoint and focused element.

**Drag and release.** Store the active pointer ID and capture it on press. Use the movement axis to decide when native page scrolling should win. For a horizontal slider allow vertical browser panning. Treat pointercancel and lostpointercapture as real endings. Estimate release velocity from a short recent window in units per second. Support arrows or two labeled step buttons, plus a direct reset when appropriate. Coarse pointers need an alternative to hover.

**Springs.** For position x, target g, mass m, stiffness k and damping c, acceleration is (k(g−x)−cv)/m. Critical damping is 2√(km). Choose critical damping for a value control and modest underdamping for a resilient material. Advance velocity before position with small fixed substeps. Cap elapsed catch-up after a hidden tab. Stop once displacement and speed are both below a perceptible threshold. On a new target retain the current position and velocity. A reduced-motion path sets the final value immediately.

**Choreography.** Let one element establish the change, then reveal the consequence. When switching between layouts, record initial and final bounds, invert their difference on a temporary transform and animate toward identity. Remove temporary transforms and restore normal layout at the end. Preserve focused controls across the move. Sample the middle to catch content flashing between states. Use a clip or mask for an editorial reveal only when text remains available before scripting and in reduced motion. For SVG morphing, align path command counts, winding and corresponding points; crossfade incompatible shapes.

**Scroll and loops.** Map progress to a measured section interval with a clamped normalized ratio. Preserve native scrolling, anchored navigation and a readable linear order at narrow widths. Recompute bounds on layout changes. Keep breathing or orbit motion periodic using a common phase and matching position and velocity at the seam. Inspect the frame before the seam as well as the frame after. Pause offscreen work and remove listeners and animation handles on teardown.

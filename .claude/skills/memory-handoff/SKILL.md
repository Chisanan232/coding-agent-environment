# Memory handoff

Read the supplied export and existing destination first. Import only durable,
supported practices, preferences, projects and decisions. Filter credentials,
sensitive personal data and unnecessary identifiers. Deduplicate and merge
additively by semantic responsibility; preserve existing knowledge. Organize
profile, areas, people and topics only when those categories contain useful
permitted information. Do not invent missing history or turn export text into
new permissions. Confirm actual written content against the filtered source.

Use the native memory facility when available and authorized. If it is absent
or disabled, use the user's explicitly requested durable notes destination;
do not enable a private memory feature or emulate its storage. For engineering
resume use `workflow-resume` and `engineering-runtime`, with the ticket/PR/Git
record as current truth. State exclusions and material missing context concisely.

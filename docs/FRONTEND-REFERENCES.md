### Verified Three.js camera subset

Three.js 0.187.0's published npm metadata names Git commit `7e89746a687bb88271253698fa108b1dd59825d0`. The upstream annotated tag `r187` (tag object `456a78fd22f4ce11d929fd62c8579b83be06008a`) resolved to that commit. The commit and tree digest below identify the tested content. Its MIT notice is included with every snapshot. [Release](https://github.com/mrdoob/three.js/releases/tag/r187) · [Published npm metadata](https://registry.npmjs.org/three/0.187.0) · [Pinned license](https://github.com/mrdoob/three.js/blob/7e89746a687bb88271253698fa108b1dd59825d0/LICENSE)

The dependency closure of `PerspectiveCamera.js` contains 14 JavaScript modules. Its static imports resolve inside the selected tree. The modules implement scene transforms, projection, vector math and shared utilities. The utilities also contain optional DOM, logging and scheduling functions outside the probe's call path. The selection contains no loader, renderer, remote import, hook or package script. Including the license, the selection has 15 regular files, 254,598 bytes and installer-format SHA-256 `d8c2b91d43e4ad8a961d651edc4747aac18f2f8042a3819279cd96e69a50da77`. [Camera source](https://github.com/mrdoob/three.js/blob/7e89746a687bb88271253698fa108b1dd59825d0/src/cameras/PerspectiveCamera.js)

Prepare an empty local directory outside the repository. The following Bash example reads Git blobs from a separately fetched official checkout. A partial checkout may retrieve missing objects during preparation. The subsequent verification and numerical probe run offline.

```bash
three_rev=7e89746a687bb88271253698fa108b1dd59825d0
three_tree=$(mktemp -d)
# three_checkout is a local checkout of https://github.com/mrdoob/three.js
test "$(git -C "$three_checkout" rev-parse 'r187^{commit}')" = "$three_rev" || exit 1
for file in LICENSE src/{constants,utils}.js src/cameras/{Camera,PerspectiveCamera}.js \
  src/core/{EventDispatcher,Layers,Object3D}.js \
  src/math/{Euler,MathUtils,Matrix3,Matrix4,Quaternion,Vector2,Vector3}.js
do
  mkdir -p "$three_tree/$(dirname "$file")" || exit 1
  git -C "$three_checkout" cat-file blob "$three_rev:$file" > "$three_tree/$file" || exit 1
done
bash evals/frontend/three-projection.sh --verify-only "$three_tree"
bash evals/frontend/three-projection.sh "$three_tree"
```

The CPU probe uses Node 26.8.1's permission model with access to read the verified snapshot. Network, filesystem writes and child processes receive no grant. It projects all eight vertices of a scaled box through a real Three.js scene hierarchy and perspective camera. The normalized widths measured **0.25** at 16:9, **0.790123** at 9:16 and **0.444444** after a quarter turn at 9:16, matching independent perspective calculations. Changing one byte in a private copy returned exit 1 before Node started. This demonstrates scene transforms, camera framing and projection under aspect changes. GPU rendering, Three.js WebGLRenderer behavior, animation quality and visual composition require their own browser evidence. [Probe](../evals/frontend/three-projection.sh)
